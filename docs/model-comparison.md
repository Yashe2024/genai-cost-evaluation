# Model Comparison

Use the same evaluation workload across candidate models.

| Dimension | Measure |
|---|---|
| Quality | Evaluation score |
| Input cost | $ / 1M tokens |
| Output cost | $ / 1M tokens |
| Latency | P50/P95 |
| Context | Maximum supported |
| Reliability | Failure rate |

Do not select a model on token price alone; evaluate total cost per business outcome.
