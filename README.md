# GenAI Cost & Token Economics

A practical framework for answering:

> What does an AI decision actually cost?

## Cost Model

`Prompt Tokens + Context Tokens + Output Tokens + Retrieval + Tool Calls + Infrastructure + Human Review = Total Cost`

## Included
- Token estimator
- Workload calculator
- Model comparison schema
- Monthly cost projection
- Unit economics
- ROI model
- Evaluation metrics

## Example
```bash
pip install -r requirements.txt
python examples/cost_demo.py
```

## Decision Metrics
- Cost / request
- Cost / 1,000 requests
- Cost / business decision
- Automation rate
- Human review rate
- Accuracy
- Latency
- ROI
